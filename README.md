**[GLOW](https://github.com/glow-bas-project)**: a Wolt-style food delivery platform, built as an R&D project with two fellow students. Seven Java microservices run on Kubernetes, with a shared CI/CD pipeline that deploys every change and rolls back automatically if smoke tests fail. It covers the full stack, including a React frontend, REST APIs, PostgreSQL, authentication with Keycloak and OpenID Connect, and deployment with Docker, Kubernetes, Helm and CI/CD.
